# 🩺 Healthcare Dataset Analysis

This project, developed as part of a data analysis course, focuses on the analysis of a comprehensive healthcare dataset. The primary goal is to uncover patterns and relationships between patient demographics, medical conditions, and associated billing costs.

---

## ✨ Features

This project is implemented as an interactive dashboard using Streamlit and includes the following features:

-   **Data Overview:** Displays a sample of the raw data used in the analysis.
-   **In-depth Visualizations:** Includes charts for the distribution of diseases, gender, age, and billing amounts.
-   **Dynamic Filtering:** Allows users to filter the data by medical condition, gender, and age range, with live-updating charts.
-   **Time-Series Analysis:** Explores the trends of various medical conditions over the years.

---

## 🛠️ Technologies Used

-   **Programming Language:** Python 3.12
-   **Libraries:**
    -   Streamlit (for the web dashboard)
    -   Pandas (for data manipulation and analysis)
    -   Seaborn & Matplotlib (for data visualization)

---

## 🚀 Setup and Installation

To run this project locally, follow these steps:

1.  Clone the repository:
    ```bash
    git clone [https://github.com/Kasraabdi/analysis_of_healthcare_dataset.git](https://github.com/Kasraabdi/analysis_of_healthcare_dataset.git)
    ```

2.  Navigate to the project directory:
    ```bash
    cd analysis_of_healthcare_dataset
    ```

3.  Install the required libraries:
    ```bash
    pip install streamlit pandas seaborn matplotlib
    ```

4.  Run the Streamlit application:
    ```bash
    streamlit run app.py
    ```
